# Portfolio — Jurema Vidal Francisco

Personal portfolio site for CV and job applications.

## Local preview

Open `index.html` in a browser, or run:

```powershell
cd C:\Users\jurem\projects\portfolio
npx --yes serve .
```

## Deploy

Hosted with GitHub Pages from the `main` branch (root).

Site URL after Pages is enabled:
`https://juremav.github.io/portfolio/`
